## Model inputs

Place these three study-specific CSVs in this directory to refit the models. The checksums in ../checksums.txt identify the exact versions.

| Required CSV | Original dataset |
|---|---|
| aps_failure_reduced_30k.csv | [APS Failure at Scania Trucks](https://archive.ics.uci.edu/dataset/421/aps+failure+at+scania+trucks) |
| ai4i2020_preprocessed.csv | [AI4I 2020 Predictive Maintenance](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset) |
| pre_conveyor_fault.csv | [Operational Conveyor Fault Dataset](https://www.kaggle.com/datasets/ziya07/operational-conveyor-fault-dataset) |

The experiment used prepared CSVs supplied for the study. The source links document provenance. Exact refitting requires the matching files, including the reduced 30,000-row APS sample. Original-to-prepared transformation scripts are unavailable.
